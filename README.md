# Latin Academy Homepage

This is the first static prototype for the Latin Academy family learning platform.

## Run it

Open `index.html` directly in a browser.

For a local web server, run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files

- `index.html` — homepage structure
- `static/styles.css` — visual design and responsive layout
- `static/app.js` — placeholder interactions
